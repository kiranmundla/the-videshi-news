# Music vetting — 2026-10-16 (pool widening)

Second vetting pass for the `videshi-pulse-reels` music pool (first pass:
2026-10-14). Ten strong-but-unused library tracks were measured and held to
the same bar as the original pool. Kiran approved widening the rotation.

## Method (calibrated)

- **Onset density**: spectral flux (STFT 2048/512 @ 22.05 kHz, mono), flux
  normalized to max, adaptive threshold = mean + 1.2·std, minimum peak
  distance 50 ms, counted over the full track. (librosa's default
  `onset_detect` over-counts ~2× on this library, so it was not used raw.)
- **BPM**: librosa `feature.tempo` with `start_bpm=140` prior.
- **Loudness**: integrated loudness, ffmpeg `loudnorm` analysis (LUFS-I);
  RMS dBFS shown for reference.

Calibration against the 2026-10-14 reference values before any candidate
was trusted:

| Calibration track | Reference (2026-10-14) | Measured (this method) | Error |
|---|---|---|---|
| pixabay-breaking-full.mp3 | 2.93 onsets/s | 2.91 onsets/s | −0.6% |
| emotional-inspiring-inspiring-uplifting.mp3 | 3.11 onsets/s, ~152 BPM | 3.15 onsets/s, 152.0 BPM | +1.4% |

Both inside ±15% (inside ±2%, in fact), and pixabay-breaking-full is again
the loudest news bed (−9.4 LUFS-I) — the scale matches the original vetting.

**Pass bar** (same spirit as 2026-10-14): onset density ≥ ~2.4/s, **or**
BPM ≥ ~140 with index energy ≥ 4.
